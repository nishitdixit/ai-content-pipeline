# Result ki chinta se chutkaara

**Tue 13 Oct 2026** · P1 Purani Wisdom · Gita ki Ek Line
**Idea:** Do the work, let go of the result; why worrying about the result ruins the work (source to verify: Gita 2.47)

> **Before recording**
> - Verify 1 quote(s) before recording

## Hook (0-3s): pick one
A: Kya tum result ki chinta mein phas gaye?
B: Main bhi sochta tha, result hi sab kuch hai.

## Relate (3-15s)
Project deadline aayi, interview ki taiyari, ya code push—har jagah bas result ki soch. Main bhi raat tak sochta tha ki client khush hoga ya promotion milega.

## Reframe (15-45s)
Gita ke adhyay 2, shlok 47 mein Krishna kehte hain—'Karmanye vadhikaraste Ma Phaleshu Kadachana'. Matlab, tumhara adhikar sirf kaam karne ka hai, phal tumhare upar nahi. Jab tum result ki chinta chhod dete ho, tab dimag poora kaam pe laga rehta hai, creativity aati hai, stress kam hota hai. Jaise software mein, code likho bina iske soche ki review perfect hoga—tab tum zyada accha code likhte ho.

## Takeaway (45-55s)
Aaj ek chhota kaam lo, bas kaam karo aur phal ki soch ko side pe rakh do.

## Soft close (55-60s)
Thoda thehro, kaam karo, sukoon milega.
Agar ye feeling bahut heavy hai, kisi se baat karo — dost, family, ya professional. Tele-MANAS helpline 14416 pe free baat kar sakte ho.
